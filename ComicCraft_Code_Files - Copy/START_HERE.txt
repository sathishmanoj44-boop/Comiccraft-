COMICCRAFT QUICK START

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   py -3.11 -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
4. Copy .env.example to .env.
5. For the first test use:
   GEMINI_MODE=mock
   IMAGE_PROVIDER=placeholder
6. Run:
   pytest -q
7. Run:
   uvicorn app.main:app --reload
8. Open:
   http://127.0.0.1:8000
9. Later, switch .env to GEMINI_MODE=real, add GEMINI_API_KEY,
   and choose IMAGE_PROVIDER=huggingface with HF_TOKEN for real images.
